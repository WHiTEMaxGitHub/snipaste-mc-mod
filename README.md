# Snipaste

Minecraft 1.20.1 客户端模组。截一块当前画面存进游戏目录，再把最新的图片贴在画面上。

## 环境

- Minecraft 1.20.1
- Forge 47.4.10
- Java 17

只声明 1.20.1。1.20 和 1.20.2 及以后的 Forge 主版本不同，不能共用这一个 jar。

## 默认按键

控制设置里可以改。

- F6：截取当前画面。拖出一块区域，松手保存。右键或 Esc 取消。
- F7：把 `snipaste` 文件夹里最新的图片贴到画面上。可以贴多张，重启游戏后浮层不保留。
- F8：编辑浮层。拖图片移动，拖边和角改大小，按住 Shift 锁定比例，滚轮改透明度。底栏可以删除、存为最新、隐藏，或打开设置。

截图保存在游戏目录的 `snipaste` 文件夹，文件名是 `snip-*.png`。文件夹总大小默认 64 MB，超出后删掉较旧的文件，最新的一张会留下。上限在设置里调整。

## 构建

```
./gradlew build
```

成品在 `build/libs`。开发时运行 `./gradlew runClient`，或在 IDEA 里跑 `runClient`。开发环境的图片和配置在 `run` 目录。
